# Sarfy

Sarfy is a lightweight Android expense-tracker app built for offline use and privacy-focused daily budgeting.

## Features
- Daily expense logging
- Offline storage with Room Database
- Monthly budget tracking
- Category breakdowns
- CSV export
- Arabic and English localization

## Build
Open in Android Studio and run the `app` module.
